# Test and Debug

Inspect package scripts, test configuration, and the failing code before acting. Reproduce the failure with the narrowest command. Read the complete relevant error. Identify root cause rather than hiding symptoms. Make a focused fix, add a regression test when appropriate, then rerun the narrow test and relevant full suite. Report exact commands and observed exit status. Distinguish tests that ran from checks that could not run. Never claim build/test success without direct evidence.
